# MyNotes

Локальное приложение для заметок под macOS (Apple Silicon, arm64) на Swift: SwiftUI + AppKit, база SQLite.
Умеет группировать, добавлять, редактировать, удалять. 
Интерфейс похож на Claude консоль, но работает с заметками.
Никаких облаков. Только локальное хранение, добавлен импорт из OneNotes.  И можно передать на другой комп через AirDrop.
Но в текущей версии пока это не тестировалось.

## Сборка и запуск

Нужны macOS 14+ и Xcode (или Command Line Tools: `xcode-select --install`).

```bash
cd MyNotes
chmod +x build.sh
./build.sh
open build/MyNotes.app
```

Скрипт собирает бинарник для arm64, рисует иконку (набор PNG → `AppIcon.icns`), собирает `MyNotes.app` и подписывает его ad-hoc.
Установка: `cp -R build/MyNotes.app /Applications/`.

Для разработки можно также открыть папку в Xcode (File → Open → `Package.swift`) или выполнить `swift run`.

## Что реализовано

| № | Функция | Как устроено |
|---|---------|--------------|
| 1 | Скрываемая левая панель проектов | Дерево проектов и заметок. Кнопки «новый проект», «новая заметка», «+» у каждого проекта (вложенный проект), контекстное меню (переименовать, переместить, удалить), перетаскивание в другой проект. Скрытие: кнопка или ⌥⌘S. Ширина меняется перетаскиванием границы. |
| 2 | Редактор | Богатый текст на `NSTextView`: жирный/курсив/подчёркивание/зачёркивание, заголовки, маркированные списки и списки задач (клик по ☐), выравнивание, ссылки, шрифты и цвета (⌘T, ⇧⌘C), вставка и перетаскивание картинок и файлов (двойной щелчок открывает вложение). Автосохранение. |
| 3 | Импорт из OneNote | См. ниже. |
| 4, 10 | Обмен между копиями MyNotes | Файл `.mynotes` (JSON). Двойной щелчок по файлу открывает его в MyNotes и импортирует заметки: новые добавляются, существующие обновляются, если импортируемая версия новее. |
| 5 | Название | MyNotes |
| 6 | Иконка | Готическая «N» (штрихи широкого пера) на бордовом фоне с золотой рамкой; рисуется кодом в `GothicN.swift`. |
| 7 | Значок в трее | Шаблонный значок «N» в строке меню. Левый клик открывает главное окно, правый — меню (открыть, новая заметка, выйти). Закрытие окна не завершает приложение. |
| 8 | Данные только локально | `~/Library/Application Support/MyNotes/mynotes.sqlite`. Сетевых запросов в приложении нет. |
| 9 | AirDrop | «Файл → Поделиться через AirDrop…» или пункт в контекстном меню заметки/проекта. Отправляется файл `.mynotes` с заметкой, проектом (с вложенными) или всем содержимым. |
| 11 | Вкладки сверху | Каждая открытая заметка — вкладка (закрыть: ⌘W, переключение: ⌥⌘← / ⌥⌘→, контекстное меню вкладки). |
| 12 | Меню | Стандартное меню macOS на русском: Файл, Правка, Формат, Вид, Окно. |

## Импорт из OneNote — важно

Напрямую читать форматы OneNote (`.one`, `.onepkg`) нельзя без закрытых библиотек, а Microsoft Graph потребовал бы вход в аккаунт и сетевые запросы — это противоречит требованию «только локально». Поэтому импорт идёт через экспорт из OneNote:

1. В OneNote выберите «Файл → Экспорт» и сохраните страницы или разделы как **Word (.docx)** (подойдут и HTML/RTF).
2. В MyNotes: «Файл → Импорт → Из OneNote…» и выберите файлы **или папки**.
3. Папки превращаются во вложенные проекты внутри проекта «OneNote», так можно сохранить структуру «блокнот → раздел → страница».

Поддерживаются `.docx`, `.doc`, `.odt`, `.rtf`, `.rtfd`, `.html`, `.htm`, `.webarchive`, `.txt`, `.md`. Файлы `.one`, `.onepkg`, `.mht`, `.pdf` пропускаются, и программа сообщит об этом.

## Передача на другие устройства Apple

Файл `.mynotes` по AirDrop уходит на любое устройство Apple, но открыть его сможет только Mac с MyNotes (версии для iPhone/iPad нет). На другом Mac скопируйте `MyNotes.app` и при первом запуске откройте через контекстное меню → «Открыть» (приложение подписано ad-hoc).

## Структура проекта

```
Package.swift
build.sh                  сборка .app под arm64
Resources/Info.plist      тип файла .mynotes, локализация
Sources/MyNotes/
  main.swift              точка входа (и режим --render-icons)
  AppDelegate.swift       окно, главное меню, трей
  Store.swift             состояние, проекты, заметки, вкладки
  Database.swift          обёртка над SQLite
  ImportExport.swift      .mynotes, AirDrop, импорт из OneNote
  EditorView.swift        редактор и команды форматирования
  SidebarView.swift       боковая панель
  ContentView.swift       окно, вкладки, пустой экран
  GothicN.swift           иконка и значок трея
  Models.swift, Dialogs.swift
```
